# Thread - Clothing Landing Page

Thread is a responsive clothing landing page built using **HTML5 and CSS3**.
The project focuses on modern layout techniques such as **Flexbox** and **responsive design** using **media queries**.

---

## Live Demo

https://thread-clothing.vercel.app/

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries

---

## Features

- Responsive navigation bar
- Hero section with call-to-action button
- Product cards section
- Mobile responsive layout
- Clean and minimal footer design
